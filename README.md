## 🎭 Character Consistency Guide (Critical)

### Mayank (28 years)
- Face: Sharp, modern Indian features, slightly arrogant expression initially
- Hair: Stylish short black hair, well-groomed
- Body: Athletic but corporate, 5'10"
- Signature look 1 (Ego phase): Expensive Italian/Parisian suit, shiny leather shoes, luxury watch, branded perfume aura
- Signature look 2 (Transformation): Simple white cotton kurta, humble posture
- Key emotion arc: Arrogance → Shock → Shame → Tears → Genuine humility

### Devashish Kaka (58 years)
- Face: Weathered, kind eyes, permanent soft spiritual smile, deep calm
- Hair: Thinning grey-black, simple
- Body: Lean, strong from physical work, slightly stooped from years of cleaning
- Signature look: Faded, washed-out white kurta (multiple times washed), yellow raincoat in rain scene, muddy from work
- Aura: Radiant inner peace, “Himalaya-like presence” even when covered in mud
- Key trait: Never judgmental, pure seva bhav

**Always use the same face reference images** for both characters when generating video (create 3-4 high-quality stills first with Flux / Midjourney / Ideogram and lock them).

## 🚀 How to Generate the Cinematic Video

1. Generate **character reference sheets** (front, 3/4, side) for Mayank & Kaka using the character bible.
2. Generate key stills for each major scene using the same character refs.
3. Feed the stills + detailed motion prompts into Kling / Runway / Luma.
4. Use the provided shot list timings matched to the voiceover (~7:43 duration).
5. Composite with the professional voiceover audio.
6. Add subtle background score (soft flute / tanpura / light rain + ambient).
